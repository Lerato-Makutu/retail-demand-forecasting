# Dataset

The dataset used in this project was obtained from:

Onurbltc — DemandForecastingDataset

Source:
https://github.com/Onurbltc/DemandForecastingDataset

The original dataset is not redistributed in this repository.

To reproduce the analysis, download `demand_forecasting.csv` from the source repository and place it in this `data/` directory.

The processed dataset, `preprocessed_demand_forecasting.csv`, is generated by running the analysis notebook and is also excluded from version control.
